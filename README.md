# When AI Gets Physics Wrong

**A physics-grounded benchmark for evaluating numerical reliability in AI-generated scientific calculations.**

Computational Physics · AI Evaluation · Numerical Verification · Python · Statistical Inference

## Can AI explain the right physics and still get the wrong answer?

Large language models can generate convincing mathematical derivations and scientific explanations. But a plausible explanation does not necessarily guarantee a numerically correct result.

In scientific computing, even a small arithmetic inconsistency can propagate through uncertainty estimates and change the final interpretation.

**When AI Gets Physics Wrong** investigates these failures using physics-inspired tasks, independent numerical reference solutions, a deterministic grader, and preserved model responses.

The project also includes an interactive 3D website connecting the underlying physics to the evaluation evidence.

## A Concrete Example: When Arithmetic Changes a Scientific Conclusion

In one geometry task, GPT-5.2 correctly identified two numerical totals:

**Baseline: 94**

**Plane result: 115**

However, the model reported their ratio as:

\[
R_{\mathrm{AI}}=1.12
\]

The correct result is:

\[
R_{\mathrm{reference}}=\frac{115}{94}\approx1.223404
\]

The discrepancy affects subsequent statistical calculations and the interpretation of the plane comparison.

Under the task's specified covariance-aware uncertainty calculation, the reference confidence interval lies above one, while the model incorrectly classifies the result as inconclusive.

**The important failure is not simply incorrect arithmetic. It is the propagation of an inconsistent intermediate result into a scientific decision.**

The original response is preserved and can be inspected in the evaluation transcripts.

The signal-search task provides an important positive control: the grader is capable of recognizing successful model outputs rather than simply classifying every response as incorrect.

The structured numerical grading is complete. Formal scientific adjudication of the full written explanations remains a separate review step.

## The Four Evaluation Tasks

### 1. WIMP Transport

Tests whether a model can reason about a random number of collisions, stochastic energy loss, and the probability of remaining above an energy threshold.

**Main challenge:** The probability that energy exceeds a threshold is not equivalent to checking whether the mean energy exceeds that threshold.

### 2. WIMP Geometry

Uses paired particle-history data to compare an ideal scoring plane with a finite-aperture geometry.

**Main challenge:** Correctly calculating ratios and uncertainties while accounting for paired observations and covariance.

### 3. Correlated Calibration

Models a synthetic measurement scenario with a common calibration uncertainty.

**Main challenge:** Correctly applying covariance-aware estimation and avoiding inconsistent numerical substitutions.

### 4. Statistical Signal Search

Tests local and global statistical significance, multiple-comparison effects, and the distinction between a detected excess and a physically identified source.

**Main challenge:** Separating statistical significance from physical interpretation.
